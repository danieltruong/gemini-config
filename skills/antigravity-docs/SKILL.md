# Antigravity documentation lookup

The mirror is 85 pages, fetched 2026-09-18, at `F:\Factory\renpy\docs\antigravity\`.

## How to look something up

1. Read `docs/antigravity/INDEX.md`. It lists every page in sidebar order with its file name,
   title, source URL, a one-sentence summary and the page's headings. Open the matching page.
2. Nothing matches: grep the text of `docs/antigravity/*.md`.

Starting points: `rules-workflows.md` for rule files and activation modes, `skills.md` for
`SKILL.md` bundles, `subagents.md` for custom agents, `hooks.md`, `mcp.md`, `permissions.md`,
`settings.md`, `agent-settings.md`.

Say so when the mirror does not cover something, instead of guessing.

Never edit files under `docs/antigravity/`. They are generated by
`python .agents/scripts/fetch-docs.py --site antigravity`, run from `F:\Factory\renpy`.

## Rule files

A rule file under `.agents/rules/` needs YAML frontmatter with a `trigger:` key. Without it the
rule is parsed, rejected and never applied; the log line is
`Invalid rule trigger: CORTEX_MEMORY_TRIGGER_UNSPECIFIED`.

Modes are `always_on` and `model_decision`, plus `glob` and `manual` (spelling unconfirmed).
`model_decision` also needs a `description:`, and `glob` takes `glob:` for one pattern or
`globs:` for several — those three keys are unconfirmed too, read out of strings in the binary.

Size limits, from the built-in `agy-customizations/docs/rules.md`: 24 KB (24,000 bytes) per
rule file, truncated on line boundaries past that, and a shared 20,000-token budget for
always-on and global rules; a rule over budget is replaced by a pointer to its file. The older
mirror page said 12,000 characters per file.

Sources: `rules-workflows.md`, "Rule activation modes", names the four modes. The built-in skill
`~/.gemini/antigravity-cli/builtin/skills/agy-customizations/SKILL.md` gives the frontmatter
spelling: "**Rules** with `trigger: model_decision` behave similarly. Only `always_on` rules are
loaded unconditionally."

The mirror does not document the frontmatter keys. Treat the spellings above as the reference.
